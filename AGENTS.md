# 5 букв — Agent instructions

Мобильная веб-игра (аналог Wordle): vanilla `index.html` + `app.js` + `styles.css` + `assets/`.

## Жёсткие правила проекта

1. Меняй **только** то, что попросил пользователь (см. `.cursor/rules/only-requested-changes.mdc`).
2. **Не меняй** игровой код, вёрстку, ассеты и тайминги «заодно».
3. Тайминги и стадии анимаций — в `АНИМАЦИИ.md` и `АНИМАЦИИ-интерфейс.md`. Сверяйся с ними; не выдумывай новые значения без просьбы.
4. Коммиты — только по явной просьбе.

## Стек

- Без React/TypeScript/сборщика
- Мобильный viewport, iOS-like UI
- Состояния игры и анимации в `app.js` / CSS transitions

## Когда можно чуть шире (и всё равно спросить)

- Правка явно ломает соседний элемент — опиши конфликт и спроси, можно ли тронуть соседнее.
- Новая фича с нуля — можно кратко предложить план, но не писать код сверх запроса без согласия.

## ECC в этом проекте

Подключён минимально: priority + light security. Без TDD, без React skills, без auto-review на каждый чих.
