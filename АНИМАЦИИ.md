## 2. Игровое поле

### 2.1. Ввод буквы — `cell-pop`

- **Триггер:** класс `.cell.filled` на ячейке с буквой.
- **Длительность:** 100 ms, `ease`.
- **Ключевые кадры:** scale 1 → 1.04 (50%) → 1.

### 2.2. Переворот ячейки при проверке слова — `revealRow()`

**Стадии (на каждую ячейку в строке):**

1. Задержка старта: `col × 150 ms` (слева направо).
2. Добавление класса `.flipped` на `.cell-inner`.
3. CSS-transition: **750 ms**, `cubic-bezier(0.4, 0, 0.15, 1)`, `rotateY(180deg)`.
4. После завершения всех ячеек строки — обновление клавиатуры + **120 ms** пауза до разблокировки ввода.

### 2.3. Ошибка дубликата слова — `shake`

- **Триггер:** класс `.grid-row.shake`.
- **Длительность:** 600 ms, `ease`.
- **Движение:** `translateX` −4px / +4px (чередование).
- Сообщение об ошибке снимается через **600 ms**.

### 2.4. Победа в строке — `cell-win-scale`

- **Триггер:** класс `.cell.win-scale` на ячейках выигрышной строки.
- **Длительность:** 1000 ms, `ease`.
- **Задержка:** `calc(var(--win-col) × 100 ms)` — волна слева направо.
- **Ключевые кадры:** 1 → 1.15 (30%) → 1.05 (40%) → 1.1 (50%) → 1.
- **Общая длительность JS-ожидания:** `(COLS − 1) × 100 + 1000` = **1400 ms**.

### 2.5. Tooltip дубликата

- Появление/скрытие: **200 ms**, `opacity` + `visibility` + `transform`.
- Автоскрытие: **1800 ms** (по умолчанию).

## 4. Экран результата и сплеши

### 4.1. Общая последовательность

**Победа:**

```
revealRow → playWinScaleAnimation (1400 ms)
→ playWinSplashAnimation (фрейм + контент; под сплешем — playNormalWordAnimation 1000 ms)
→ [если «Тематическое слово»] playThematicSplashAnimation
   ИНАЧЕ [если «Сплеш уведомлений»] playNotifySplashAnimation
→ [если «Прогресс заданий»] playTasksProgressSplashAnimation
→ fade-out фрейма сплеша (600 ms; hero стартует на 70% fade)
→ playWinHeroAnimation (800 ms, параллельно с прогрессом)
```

**Поражение (6 попыток):**

```
revealRow → playLoseSplashAnimation (фрейм + контент + переворот ответа;
  под сплешем — playNormalWordAnimation 1000 ms)
→ [если «Тематическое слово»] playThematicSplashAnimation
→ [если «Прогресс заданий»] playTasksProgressSplashAnimation
→ fade-out фрейма сплеша (600 ms; hero на 70% fade)
→ playWinHeroAnimation (800 ms, без слова / прогресса слова)
```

**Цепочка follow-up:** следующий сплеш стартует на **70%** content-out предыдущего (`WIN_SPLASH_SECONDARY_AT`).  
**К результату:** content-out последнего сплеша ждётся **70%** (`WIN_SPLASH_RESULT_AT`), затем fade-out; hero стартует на **70%** fade-out (сам fade доигрывает 600 ms).  
«Тематическое слово» и «Сплеш уведомлений» взаимно исключают друг друга в профиле. «Прогресс заданий» независим и всегда последний в цепочке.  
Сплеш уведомлений после поражения **не** показывается.

**Easing контента сплешей победы / thematic / notify / tasks:** `cubic-bezier(0.25, 1.4, 0.65, 1.3)`.  
**Easing заполнения прогресса / кнопки на сплеше заданий:** `cubic-bezier(0.45, 1.45, 0.8, 1)`.  
**Фрейм сплеша:** `#win-splash`, от верхней границы `.nav-row` до низа, фон `#1C1C1E`.  
Кнопка «Закрыть» остаётся над сплешем и кликабельна.

### 4.2. Сплеш победы — `playWinSplashAnimation()`

**Классы режима:** `.win-splash--win`, стадии `.is-fading-in` / `.is-content-in` / `.is-title-in` / `.is-content-out` / `.is-fading-out`.

| Стадия | Длительность | Easing | Что происходит |
|--------|--------------|--------|----------------|
| Fade-in фрейма | 600 ms | `ease-in` | opacity фрейма 0 → 1 |
| Пауза | 200 ms | — | Пустой фрейм |
| Content-in | 700 ms | `cubic-bezier(0.25, 1.4, 0.65, 1.3)` | Картинка `assets/Verh.png` 260×200: opacity 0→1, `scale(1.2→1.0)`. Кнопки opacity 0→1. Параллельно `playNormalWordAnimation()` |
| Confetti | старт на **30%** content-in (= 210 ms) | — | Радиальный burst конфетти из центра картинки |
| Title-in | старт на **60%** content-in (= 420 ms) | 700 ms, тот же bezier | Заголовок / подзаголовок opacity 0→1; `padding-top` copy 24→8 px; margin подзаголовка 28→12 px; gap картинка→copy 4 px |
| Content-out («Пропустить») | 1000 ms (ожидание **70%** = 700 ms при follow-up или к результату) | bezier | Контент opacity 1→0; отступы обратно 8→24 / 12→28 |
| Fade-out фрейма | 600 ms | `ease-in` | После всех follow-up; hero на **70%** |

**Ранний «Пропустить»:** уходит в `finishSplashTowardResult` — при включённых follow-up сначала цепочка thematic/notify → tasks, затем fade-out.

**Конфетти сплеша:** 200 частиц, `mode: "radial"` из центра картинки (`playSplashConfetti()`).

### 4.3. Сплеш поражения — `playLoseSplashAnimation()`

**Классы режима:** `.win-splash--lose`. Без конфетти.

| Стадия | Длительность | Easing | Что происходит |
|--------|--------------|--------|----------------|
| Fade-in фрейма | 600 ms | `ease-in` | opacity 0 → 1 |
| Пауза | 200 ms | — | Пустой фрейм |
| Content-in | 700 ms | bezier | Заголовок «Не отгадали слово», подзаголовок «Мы загадали:», ряд из 5 ячеек (1:1, gap 6 px, поля 52 px), «Коснитесь, чтобы продолжить». Параллельно `playNormalWordAnimation()` |

| Fade-out фрейма | 600 ms | `ease-in` | После thematic / tasks; hero на **70%** |

**Ранний тап:** та же цепочка follow-up, что ранний Skip на победе (без notify).

### 4.4. Сплеш тематического слова — `playThematicSplashAnimation()`

**Когда:** после content-out победы/поражения, если включено «Тематическое слово».  
**Класс режима:** `.win-splash--thematic`. Паузы перед контентом нет.

| Стадия | Длительность | Easing | Что происходит |
|--------|--------------|--------|----------------|
| Content-in | 1000 ms | `cubic-bezier(0.25, 1.4, 0.65, 1.3)` | Body opacity 0→1; изображение `scale(0.9→1.0)`; отступы слово↔картинка и картинка↔подзаголовок **24→4** px |
| Content-out («Пропустить») | 1000 ms (ожидание **70%**, если дальше tasks / результат) | bezier | Body opacity 1 → 0; отступы **4→24** px |

Кнопка «Открыть вклад» — без действия.

## 7. Карусель призов (вкладка «Призы» → «Можно выиграть»)

Карусель живёт на экране призов. Переключатель профиля **«Активная стадия»**: вкл. — карусель; выкл. — заглушка Hero (вкладка «Задания» и монеты остаются).

Intro и участие запускаются при открытии вкладки «Призы», если стадия активна.

### 7.1. Карусель — `updateCardTransforms()`

Интерполяция по `progress` = `min(1, |offset| / RAFFLE_SLIDE_STEP)` (0 = центр, 1 = бок):

| Параметр | Центр (0) | Бок (1) |
|----------|-----------|---------|
| `scale` (wrap) | 1 | 0.9 |
| `translateY` | 0 px | 48 px |
| `opacity` | 1 | 0.75 |
| `rotate` | centerRotate × (1−p) + offset/step × 4° | — |
| `visual scale` | 1 | 0.9 |

**centerRotate:** `[+1°, −2°, 0°]` по `data-card-index`.

Обновление: `scroll` (RAF) + `scrollend` (debounce **120 ms**). Слайды `0…2` без лупа.

### 7.2. Подпись над пагинацией — `updateRafflePaginationLabelOpacity()`

Текст «Подведём итоги 1 декабря» (`.raffle-cards-pagination-label`):

```
distanceFromSnap = |scrollProgress − round(scrollProgress)|
opacity = 1 − min(1, distanceFromSnap × 2)
```

- Карточка в центре snap → **opacity 1**.
- Между snap-позициями (середина скролла) → **opacity 0**.
- Пересчёт на каждом кадре скролла (без CSS-transition).
- Во время intro (`is-intro-active`, `raffleIntroRunning`) — управляется отдельно (см. §7.4).

### 7.3. Переворот карточки тапом — `toggleRaffleCardFlip()`

- **750 ms**, `cubic-bezier(0.4, 0, 0.15, 1)`.
- Накопительный `rotateY` (+180° за тап).

### 7.4. Участие в розыгрыше — `runRaffleParticipate()`

## 13. Онбординг

Сценарий обучения: ответ **`БУКВА`**, шаги **`ДЕБЮТ` → `БЛЕСК` → свободный ввод**. Сплешей нет. Бейджи в сценарии только визуал **0 / 9** (не из игрового стейта); после выхода — снимок как было.

Во время `scenario-onboarding-result` у карточки заданий `data-task-id="1"` временно текст «Включите уведомления / в игре «5 букв»»; после выхода — исходный.

### 13.1. Старт / закрытие экрана

| Этап | Длительность | Класс / действие |
|------|--------------|------------------|
| Уход игры | 600 ms | `.is-onboarding-transition` + `.is-onboarding-leave` |
| Появление онбординга | 600 ms | `#onboarding.is-open` → `.is-settled` |
| Intro-модалка open/close | 300 / 300 ms | `#onboarding-intro` |
| Закрытие → профиль | 600 ms | снятие `.is-open`, restore chrome |

### 13.2. Плашка, spotlight, тултип клеток

| Элемент | Тайминг | Easing / детали |
|---------|---------|-----------------|
| Смена текста плашки | 400 ms opacity out/in | `cubic-bezier(0.2, 0, 0.4, 0.9)` |
| Spotlight клеток | 3000 ms | `.is-spotlight`, `.is-spotlight-target` |
| Тултип над строкой | in 300 / hold 3000 / out 150 ms | scale + opacity |
| Help-reveal строк | 600 + 600 ms | `.is-help-reveal` |

### 13.3. Handoff к экрану результата — `finishOnboardingToResult()`

**Без сплеша.** Последовательность:

1. Пауза **400 ms** после флипа (`ONBOARDING_FLIP_TO_SCALE_MS`).
2. `prepareOnboardingResultContent()` → `.scenario-onboarding-result`, бейджи 0/9, жёлтая «Играть ещё за 3», карточка обучения, подмена текста карточки №1.
3. Handoff: `.is-result-handoff` + `.is-tab-handoff` → `.is-tab-handoff-in` / `.is-onboarding-tab-in`.
4. Параллельно (**600 ms**): схлопывание диалога (height → 0, контент гаснет к ~450 ms), выезд тапбара, `playOnboardingWinScaleAnimation` (как `cell-win-scale`).
5. Скрытие оверлея онбординга → `playNormalWordAnimation` (**1000 ms**) → конфетти → `playWinHeroAnimation` (**800 ms**).
6. Пауза **600 ms** → тултип заданий.

### 13.4. Тултип заданий — `prepareOnboardingTaskHint` / `revealOnboardingTaskTooltip`

| Этап | Длительность |
|------|--------------|
| Dim + ожидание | 500 ms (`ONBOARDING_TASK_TOOLTIP_DELAY_MS`) |
| Появление тултипа | 300 ms opacity + scale, `cubic-bezier(0.4, 0.1, 0.2, 1)` |
| Якорь | хвост над табом «Задания», тело слева |

Классы: `.is-onboarding-notify-dim`, `.is-onboarding-task-hint`. Тап по «Задания» снимает хинт.

### 13.5. Тултип призов — `startOnboardingPrizesHint`

После claim обучения:

| Этап | Длительность |
|------|--------------|
| Задержка | 300 ms |
| Появление / скрытие | 300 ms opacity + scale |
| Якорь | хвост над табом «Призы», тело **по центру хвоста** (clamp 16 px) |

Класс: `.is-onboarding-prizes-hint`. Клик куда угодно скрывает. Без затемнения экрана (в отличие от energy-hint ранее).

### 13.6. Первый заход в «Призы» в прогоне

| Поведение | Детали |
|-----------|--------|
| Первый визит | `.is-onboarding-owned-preview`, сегмент «Уже у вас», видна только верхняя карточка |
| Повтор / выход | сегмент «Можно выиграть», превью снято |

### 13.7. Штора правил

Как штора результата: open **500 ms**, close **300 ms**. Классы `#onboarding-rules-sheet` / backdrop.
